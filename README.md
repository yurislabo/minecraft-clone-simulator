# Minecraft Clone Simulator / マイクラ・クローン学習シミュレーター

マインクラフトの /clone コマンドの仕組みを直感的に理解するための学習ツールです。

## ✨ このツールでできること / Features

- 座標（ざひょう）の学習: 自分を中心とした ~（相対座標）の数え方を学べます。
- 範囲選択: 始点と終点でブロックを囲む感覚を身につけられます。
- 目的地（お引越し先）のルール: 選択範囲のどの角が目的地に重なるかを視覚的に確認できます。
- オプションの実験: masked と replace の違いをシミュレーションできます。

## 🚀 使い方 / How to Use

1. じゅんびモード (Setup): グリッドをクリックして好きなブロックを置きます。
2. 範囲選択 (Select Range): コピーしたい範囲の2つの角を選びます。
3. 目的地選択 (Destination): 移動させたい場所を選びます。
4. 実行 (Execute): 「魔法を実行」ボタンを押すと、ブロックが移動します。
